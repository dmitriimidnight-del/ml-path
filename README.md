# ml-path

Личный инструмент для пути к ML-инженеру: шесть проектов в портфолио на одном корпусе английской поэзии, от анализа данных до сервиса с LLM.

Открыть приложение: https://dmitriimidnight-del.github.io/ml-path/

## Что внутри

- Вводный урок «Что такое ML».
- Лестница из шести проектов с оценкой сроков.
- Для каждого проекта: бриф, уроки, недельный план, критерии готовности.
- В каждом уроке: объяснение простым языком, примеры кода с реальным выводом, частые ошибки, упражнения с решениями, словарик терминов на английском, квиз и ссылки на источники.
- Прогресс сохраняется в браузере. Между устройствами он переносится кодом (внизу главной страницы).

Сейчас подробно расписаны вводный урок и три проекта:

- проект 1, семь уроков: установка, Python, Git, данные, pandas, графики, статистика;
- проект 2, восемь уроков: векторы, TF-IDF, разбиение данных, логистическая регрессия, градиентный спуск, метрики, переобучение, pipeline;
- проект 3, семь уроков: структура проекта, HTTP и JSON, FastAPI, тесты, Docker, CI, надёжность сервиса.

Проекты 4–6 добавляются следующими.

## Как проверялся материал

- Код из уроков запускается скриптом `tools/check_lessons.py`: он выполняет каждый пример и упражнение на Python и сверяет вывод с тем, что показано в приложении. Последний запуск: 99 блоков, 66 сверок вывода, расхождений нет (Python 3.13, numpy 2.5, pandas 3.0, matplotlib 3.11, scikit-learn 1.9, pydantic 2.13).
- Файлы проекта 3 из уроков собраны в отдельный эталонный проект. В нём реально запускались: обучение учебной модели, `app/model.py`, тесты модели через `pytest`, линтер `ruff`, разбор файла CI.
- Ссылки в разделах «Источники» ведут на официальную документацию.

Что не запускалось:

- `app/main.py`, `tests/test_api.py`, `Dockerfile` и команды `docker` из проекта 3: в среде проверки нет FastAPI и работающего Docker. Они написаны по официальной документации FastAPI.
- Скрипт скачивания стихов из PoetryDB: проверен на ответе той же формы, но не на живом сервисе.
- Команды установки для Windows и macOS в уроке «Установка».

## Как устроено

Статический сайт без сборки и зависимостей.

| Файл | Назначение |
|---|---|
| `index.html` | Страница |
| `styles.css` | Оформление, светлая и тёмная темы |
| `data.js` | Вводный урок, проект 1 и краткие описания остальных проектов |
| `lessons-p1-extra.js` | Проект 1: уроки про установку и статистику |
| `lessons-p2.js` | Проект 2: уроки, план и критерии |
| `lessons-p3.js` | Проект 3: уроки, план и критерии |
| `tools/check_lessons.py` | Проверка: запускает код из уроков и сверяет вывод |
| `app.js` | Логика: экраны, прогресс, перенос между устройствами |

Чтобы изменить или добавить материал, правь файлы с уроками, затем запусти `python tools/check_lessons.py`.

## Запуск на своём компьютере

Открой `index.html` в браузере.
