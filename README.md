# ml-path

Личный инструмент для пути к ML-инженеру: шесть проектов в портфолио на одном корпусе английской поэзии, от анализа данных до сервиса с LLM.

Открыть приложение: https://dmitriimidnight-del.github.io/ml-path/

## Что внутри

- Вводный урок «Что такое ML».
- Лестница из шести проектов с оценкой сроков.
- Для каждого проекта: бриф, уроки, недельный план, критерии готовности.
- В каждом уроке: объяснение простым языком, примеры кода с реальным выводом, частые ошибки, упражнения с решениями, словарик терминов на английском, квиз и ссылки на источники.
- Прогресс сохраняется в браузере. Между устройствами он переносится кодом (внизу главной страницы).

Сейчас подробно расписаны вводный урок и первый проект (пять уроков), остальные добавляются по мере прохождения.

## Как проверялся материал

- Все примеры кода запущены (Python 3.13, pandas 3.0, matplotlib 3.11, git 2.43), вывод в уроках скопирован из реального запуска.
- Ссылки в разделах «Источники» ведут на официальную документацию: Python, pandas, matplotlib, Git, Google ML, Project Gutenberg.
- Скрипт скачивания стихов из PoetryDB проверен на ответе той же формы, но не на живом сервисе.

## Как устроено

Статический сайт без сборки и зависимостей.

| Файл | Назначение |
|---|---|
| `index.html` | Страница |
| `styles.css` | Оформление, светлая и тёмная темы |
| `data.js` | Всё содержимое: проекты, теория, квизы, планы |
| `app.js` | Логика: экраны, прогресс, перенос между устройствами |

Чтобы изменить или добавить материал, достаточно править `data.js`.

## Запуск на своём компьютере

Открой `index.html` в браузере.
