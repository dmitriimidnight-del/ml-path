# ml-path

Личный инструмент для пути к ML-инженеру: шесть проектов в портфолио на одном корпусе английской поэзии, от анализа данных до сервиса с LLM.

Открыть приложение: https://dmitriimidnight-del.github.io/ml-path/

## Что внутри

- Вводный урок «Что такое ML».
- Лестница из шести проектов с оценкой сроков.
- Для каждого проекта: бриф, уроки, недельный план, критерии готовности.
- В каждом уроке: объяснение простым языком, примеры кода с реальным выводом, частые ошибки, упражнения с решениями, словарик терминов на английском, квиз и ссылки на источники.
- Кнопка «Запустить» у примеров на чистом Python, numpy, pandas, matplotlib и scikit-learn: код выполняется прямо в браузере, его можно менять. У упражнений есть редактор и сверка с решением. Python (Pyodide) скачивается при первом нажатии.
- Режим «предскажи результат»: вывод примера скрыт, пока не запишешь свой прогноз или не нажмёшь «Показать ответ». Отключается переключателем в начале урока.
- Живые графики с ползунками: градиентный спуск, сигмоида, порог решения и precision/recall, температура языковой модели. При значениях по умолчанию показывают те же числа, что в уроке.
- Повторение по расписанию: вопросы, в которых ошибся, возвращаются через 1 день, затем через 3, 7 и 16 дней. На главной странице появляется карточка «Повторение».
- Входная диагностика по базе Python: 19 вопросов, результат по темам со ссылками на уроки и главы официального учебника, отметки «можно пролистать» и «подтянуть» в списке уроков.
- Карточки терминов в повторении и словарь всех терминов с поиском. Термины урока добавляются в повторение, когда отвечены все вопросы квиза.
- Недельная цель в часах, отметка времени занятий и серия дней подряд.
- Работает без интернета: уроки, квизы, графики и прогресс сохраняются на устройстве после первого открытия. Python для кнопки «Запустить» скачивается для офлайна кнопкой на главной странице.
- Блок «Не понял? Спроси Claude» в каждом уроке и кнопка «Спросить Claude» у ошибки запуска: открывают новый чат claude.ai с готовым текстом вопроса (тема урока, код и текст ошибки). Текст нужно проверить и отправить самому.
- Тренировки «Найди ошибку» и «Собери код» в 10 уроках, всего 19 заданий. «Собери код» принимает любой порядок строк, который печатает нужный результат.
- Вкладка «Контрольная» в каждом проекте: 15 вопросов из всех уроков проекта, сдана при 80 % верных, ошибки уходят в повторение, каждая пересдача — новый набор. Сданная контрольная отмечена на главной.
- Кнопка «Проверить репозиторий» во вкладке «Готовность»: через открытый API GitHub смотрит, публичный ли репозиторий, есть ли описание, подробный английский README с картинкой, requirements.txt, .gitignore, не меньше 5 коммитов с английскими сообщениями и файлы, нужные конкретному проекту (ноутбук, train.py, Dockerfile и CI, тесты, DECISIONS.md).
- «Мой конспект» под каждым уроком: заметка своими словами сохраняется сама. Страница «Мои заметки» собирает все заметки и ответы на вопросы собеседования, кнопка выгружает их одним файлом Markdown.
- Тренажёр собеседования: 33 вопроса на английском по шести проектам, с переводом. Сначала отвечаешь сам, потом открываешь пункты, которые должны быть в ответе, и отмечаешь, что назвал. Каждый вопрос ссылается на урок, где разобрана тема. Кнопка отправляет вопрос и твой ответ в Claude для разбора и правки английского.
- Синхронизация телефона и компьютера через приватный репозиторий на GitHub (`ml-path-progress`, файл `progress.json`) и токен доступа только к этому репозиторию. Изменения отправляются через 15 секунд после правки и при сворачивании приложения, подтягиваются при открытии. Если прогресс менялся на обоих устройствах между синхронизациями, он объединяется без потерь: выполненное остаётся выполненным, из двух версий заметки берётся более новая. Токен хранится только в браузере устройства и в код прогресса не попадает.
- Без GitHub прогресс можно перенести кодом (внизу главной страницы).

- Урок разбит на части по 30–40 минут. В начале урока оглавление с отметками прочитанных разделов. Приложение запоминает раздел, на котором ты остановился: на главной появляется карточка «Продолжить с места», а при открытии урока — кнопка «Продолжить».
- Вопросы стоят сразу после разделов, где разбирается их тема, а в конце урока — итог и список разделов, где остались вопросы без ответа. Без вопроса остались только шаги установки и вводные разделы; разделы с кодом проверяет ещё и режим «предскажи результат».
- «Главное по-английски» в каждом уроке: пересказ урока простым английским с кнопкой «Послушать». Кнопка 🔊 у английских терминов в уроках, словаре и карточках повторения и у вопросов тренажёра собеседования (озвучивает браузер). В тренажёре можно отвечать голосом: браузер распознаёт английскую речь и записывает ответ в поле. Голосовой ввод показывается, только если браузер его поддерживает, обычно для распознавания нужен интернет.

Подробно расписаны вводный урок и все шесть проектов, всего 40 уроков и 217 вопросов:

- проект 1, семь уроков: установка, Python, Git, данные, pandas, графики, статистика;
- проект 2, восемь уроков: векторы, TF-IDF, разбиение данных, логистическая регрессия, градиентный спуск, метрики, переобучение, pipeline;
- проект 3, семь уроков: структура проекта, HTTP и JSON, FastAPI, тесты, Docker, CI, надёжность сервиса;
- проект 4, семь уроков: матрицы, нейрон и нелинейность, обратное распространение, PyTorch, эмбеддинги, обучение на практике, внимание и готовые модели;
- проект 5, шесть уроков: поиск по смыслу, индекс, метрики поиска, языковые модели, RAG, честность и стоимость ответов;
- проект 6, четыре урока: идея и объём, архитектура, публикация, портфолио и собеседование.

## Как проверялся материал

- `tools/check_runner.py` прогоняет через `runner.py` каждый пример, у которого есть кнопка «Запустить», в том же порядке и с той же общей памятью, что в приложении. Последний запуск: 108 примеров, вывод совпал у всех 106 примеров с показанным выводом, 2 графика построены, 44 решения упражнений выполнились без ошибок.
- Интерфейс запуска проверен в браузере на ширине телефона, при этом Pyodide был подменён обычным Python. Сам Pyodide с CDN при проверке не загружался: в среде проверки он недоступен.

- Код из уроков запускается скриптом `tools/check_lessons.py`: он выполняет каждый пример и упражнение на Python и сверяет вывод с тем, что показано в приложении. Последний запуск: 158 блоков, 106 сверок вывода, расхождений нет (Python 3.13, numpy 2.5, pandas 3.0, matplotlib 3.11, scikit-learn 1.9, pydantic 2.13).
- Файлы проекта 3 из уроков собраны в отдельный эталонный проект. В нём реально запускались: обучение учебной модели, `app/model.py`, тесты модели через `pytest`, линтер `ruff`, разбор файла CI.
- Ссылки в разделах «Источники» ведут на официальную документацию.

- Работа без интернета проверена в браузере: приложение открыто с сетью, затем сеть отключена — уроки, графики и запуск кода после скачивания Python работают. Pyodide при этом был подменён, настоящая загрузка с CDN не проверялась.

- Задания «Найди ошибку» и «Собери код» собирает `tools/build_exercises.py`: он запускает исправный и сломанный код, проверяет, что они различаются ровно одной строкой и печатают показанные в задании значения, и перебирает все перестановки строк, чтобы найти каждый верный порядок.
- Тренировки, контрольная, кнопки «Спросить Claude» и проверка репозитория проверены в браузере на ширине телефона. Ответы GitHub при этом были подставлены в том же формате, что у настоящего API; живые запросы к api.github.com из браузера не делались. Открытие claude.ai с готовым текстом проверено только по сформированной ссылке.

- Заметки, выгрузка, тренажёр собеседования и синхронизация двух устройств проверены в браузере. GitHub при этом был заменён имитацией с тем же форматом ответов: чтение и запись файла, отказ при устаревшем `sha`, отказ при неверном токене. Проверены первое подключение, слияние прогресса двух устройств, передача снятой отметки, одновременные правки и отказ подключать публичный репозиторий. Живой GitHub из браузера не вызывался.

- Ссылки на источники во всех уроках проверены в ноябре 2026 года: все открываются и ведут на нужную тему. Утверждения, которые нельзя проверить запуском кода, сверены с официальной документацией: версии Python и GitHub Actions, сохранение моделей в PyTorch, пример Claude API, размер вектора и предел длины all-MiniLM-L6-v2, условия Render, Streamlit Community Cloud и Hugging Face Spaces, название кода HTTP 422, формула IDF в scikit-learn.

- Вопросы после разделов собирает `tools/build_checks.js`. Каждый старый вопрос относится к разделу, с которым у него больше всего общих слов; результат просмотрен вручную, три вопроса перенесены в OVERRIDES. 37 новых вопросов написаны по тексту своих разделов и дописаны в конец квизов, поэтому сохранённые ответы не сбились. Пересказы на английском в `english.js` написаны по содержанию уроков.
- Оглавление, части, место остановки, вопросы после разделов, озвучка и голосовой ввод проверены в браузере на ширине телефона. Озвучка и распознавание речи при этом были подменены, потому что в среде проверки нет звука и микрофона; как звучит голос на конкретном телефоне, зависит от установленных в системе голосов.

Что не запускалось:

- `app/main.py`, `tests/test_api.py`, `Dockerfile` и команды `docker` из проекта 3: в среде проверки нет FastAPI и работающего Docker. Они написаны по официальной документации FastAPI.
- Код на PyTorch и Sentence Transformers из проекта 4 (блоки с пометкой `torch`): в среде проверки нет этих библиотек. Он написан по официальной документации, и вывод для него в уроках не показан. Вся математика проекта 4 (матрицы, обратное распространение, обучение сети на XOR, внимание) написана на numpy и проверена запуском.
- Обращение к API языковой модели и код с Sentence Transformers в проекте 5, код интерфейса на Streamlit в проекте 6 (блоки с пометкой `external` или `torch`): нужны ключ, интернет или библиотеки, которых нет в среде проверки. Сведения о бесплатных хостингах в проекте 6 проверены по их документации в ноябре 2026 года.
- Скрипт скачивания стихов из PoetryDB: проверен на ответе той же формы, но не на живом сервисе.
- Команды установки для Windows и macOS в уроке «Установка».

## Как устроено

Статический сайт без сборки и зависимостей.

| Файл | Назначение |
|---|---|
| `index.html` | Страница |
| `styles.css` | Оформление, светлая и тёмная темы |
| `data.js` | Вводный урок, проект 1 и краткие описания остальных проектов |
| `lessons-p1-extra.js` | Проект 1: уроки про установку и статистику |
| `lessons-p2.js` | Проект 2: уроки, план и критерии |
| `lessons-p3.js` | Проект 3: уроки, план и критерии |
| `lessons-p4.js` | Проект 4: уроки, план и критерии |
| `lessons-p5.js` | Проект 5: уроки, план и критерии |
| `lessons-p6.js` | Проект 6: уроки, план и критерии |
| `sw.js` | Сервис-воркер: работа без интернета |
| `tools/check_offline.py` | Проверка: все файлы приложения сохраняются для офлайна |
| `diagnostic.js` | Вопросы входной диагностики |
| `tools/check_diagnostic.py` | Проверка: правильные ответы диагностики совпадают с реальным выводом кода |
| `widgets.js` | Живые графики с ползунками |
| `runner.py`, `runner.js` | Запуск Python в браузере: загрузка Pyodide, выполнение примеров, графики, понятные ошибки |
| `tools/check_runner.py` | Проверка: прогоняет примеры с кнопкой «Запустить» через runner.py |
| `tools/check_lessons.py` | Проверка: запускает код из уроков и сверяет вывод |
| `app.js` | Логика: экраны, прогресс, перенос между устройствами |

Чтобы изменить или добавить материал, правь файлы с уроками, затем запусти `python tools/check_lessons.py`.

## Запуск на своём компьютере

Открой `index.html` в браузере.
